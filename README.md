git init : initialise le dépot

```bash
git init
```

git status : etat des fichier

```bash
git status
```

git add : ajoute un fichier au staging

```bash
git add README.md
```

git commit -m "texte" : ajoute les modification dans l'hystorique

```bash
git commit -m "Ajoute le README"
```

git pull : récupère les modification effectuer sur le dépot github

```bash
git pull origin main
```

git push : envoie les modification réaliser sur le dépot github

```bash
git push origin main
```

git branch : liste les différente branche

```bash
git branch
```

git merge : réalise la fusion de deux branche

```bash
git merge feature/exemples
```

git switch : change de branche

```bash
git switch main
```

git log : affiche les commits

```bash
git log --oneline
```

git diff : affiche les modification qui ne sont pas encore ajouter au staging

```bash
git diff README.md
```
